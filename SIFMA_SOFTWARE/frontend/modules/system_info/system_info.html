Arquitectura y Entorno de Ejecución

Operativo
Arquitectura del Software: SIFMA Desktop Híbrido (Tauri 2.0 + Python Engine)
Compilador de Núcleo: Rust 1.99.1 (LLVM nativo)
Motor de Persistencia: SQLite 3 (Modo WAL con transacciones ACID)
Subsistema de Visión e IA: Python 3.10+ (Subproceso Sidecar IPC)
Plataforma Host: Microsoft Windows x86_64
Contenedor Gráfico: Microsoft Edge WebView2 (Aceleración de Hardware)

Protocolo de Comunicación de Hardware

El puerto serie opera mediante un hilo asíncrono no bloqueante en Rust (`serialport-rs`), desacoplado del renderizado de la interfaz.

Formato de Trama Válido: $pH,EC,Turb,DO,T_agua,T_ext,HR,Motor#
