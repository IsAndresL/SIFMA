memory Topología de Hardware, Sensores & Visión
dns
Estructura Aeropónica Vertical:
Torre vertical modular con canastillas distribuidas para cultivo en aeroponía/hidroponía, equipada con sistema de aspersión y recirculación de solución nutritiva controlada.
photo_camera
Sistema de Visión Fenotípica Dual:
Cámara Cenital superior calibrada para segmentación del canopia vegetal (área foliar en cm² y verdor) y Cámara Lateral para estimación de altura y diámetro del tallo.
sensors
Matriz de Telemetría Fisicoquímica y Ambiental:
Monitoreo continuo de solución (pH, Conductividad Eléctrica μS/cm, Turbidez NTU, Oxígeno Disuelto mg/L, Temperatura del Agua), Microclima ambiental (Temperatura, Humedad, Radiación Solar UV) y Corriente de Bombeo (ACS712).
settings_input_antenna
Enlace de Adquisición y Sincronización:
Transmisión inalámbrica por radiofrecuencia (XBee / RF) con enlace serial USB hacia el servidor local SIFMA e importador universal CSV por jornadas horarias (07:00, 12:00, 17:00).
layers Arquitectura de Software y Stack
Patrón Arquitectural: Clean Architecture (Domain, Application, Infrastructure, Presentation)
Servidor Web: Python 3.10+ / Flask 3.0 / Werkzeug / Jinja2
Visión Computacional: OpenCV (cv2) 4.8+, NumPy, Segmentación HSV + CIELAB + Filtros Morfológicos y Umbralización Adaptativa
Base de Datos: SQLite3 con SQLAlchemy ORM y capa de repositorios transaccionales
Visualización & UI: Chart.js, Vanilla CSS Moderno, Heatmaps multivariables de Pearson y CSS Paged Media para Dossiers PDF
