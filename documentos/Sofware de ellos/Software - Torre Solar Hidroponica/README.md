# Dashboard Torre Hidropónica Solar - Vertical Ascend

Este software es un **Dashboard de monitoreo y control** diseñado para la torre hidroponica solar desarrollada por **vertical Ascend**.  
Permite visualizar y registrar en tiempo real variables ambientales y eléctricas de la torre, integrando datos desde sensores conectados vía puerto serial.

---

## Funcionalidades principales
- Gráficas en tiempo real de:
  - Temperatura ambiente
  - Humedad relativa
  - Radiación UV
  - Corriente del motor
- Registro y exportación de datos a CSV.
- Control de conexión: conectar, pausar, desconectar.
- Visualización del logo de la empresa.
- Compatible con el sistema solar y protección integrada de la torre.
